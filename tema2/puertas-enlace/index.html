    Puertas de enlace

    Tema 2. Puertas de enlace y comunicación entre redes

    1. ¿Cómo se comunica un equipo con otro?

    Cuando un ordenador quiere enviar información a otro equipo, primero debe determinar si el destino está en su misma red IP o en una red diferente.

    Esta decisión es fundamental para comprender el funcionamiento de las redes.

    Imaginemos una red local con dos ordenadores:

    Equipo Dirección IP Máscara
    Ordenador A 192.168.1.10 255.255.255.0
    Ordenador B 192.168.1.20 255.255.255.0

    Ambos pertenecen a la red 192.168.1.0/24.

    Si el ordenador A quiere enviar información al ordenador B, puede hacerlo directamente a través de la red local, sin necesidad de que un router encamine el tráfico entre redes.

    Ahora imaginemos que el destino es 192.168.2.20. Con la misma máscara /24, este equipo pertenece a otra red: 192.168.2.0/24.

    En ese caso, el ordenador A necesita utilizar un router que pueda encaminar el tráfico hacia la red de destino.

    2. El papel de la máscara de red

    La máscara o el prefijo permiten al equipo identificar qué parte de una dirección IP corresponde a la red.

    Por ejemplo, con el prefijo /24:

    • 192.168.1.10/24 pertenece a 192.168.1.0/24.
    • 192.168.1.20/24 pertenece a 192.168.1.0/24.
    • 192.168.2.20/24 pertenece a 192.168.2.0/24.

    Por tanto, los dos primeros equipos están en la misma subred, mientras que el tercero está en una subred diferente.

    Importante: no basta con comparar visualmente las direcciones IP. La decisión depende de la dirección IP y de su máscara o prefijo.

    3. ¿Qué es una puerta de enlace?

    Una puerta de enlace es un equipo o dispositivo que permite comunicar una red con otras redes.

    En una red IP, la puerta de enlace predeterminada suele ser la dirección de una interfaz de un router conectado a la red local.

    Por ejemplo:

    Dispositivo Dirección IP
    Ordenador A 192.168.1.10/24
    Router, interfaz LAN 192.168.1.1/24
    Ordenador B, otra red 192.168.2.20/24

    El ordenador A puede utilizar 192.168.1.1 como puerta de enlace para enviar tráfico hacia destinos que no estén en su red local, siempre que exista una ruta adecuada.

    La puerta de enlace debe ser alcanzable desde la red local y la configuración de rutas debe permitir la comunicación.

    4. Router y puerta de enlace: ¿son lo mismo?

    Aunque a menudo se utilizan como si fueran sinónimos, no significan exactamente lo mismo.

    Router

    Es un dispositivo o sistema que reenvía paquetes IP entre redes utilizando su tabla de rutas.

    Puerta de enlace predeterminada

    Es el siguiente salto que utiliza un equipo cuando necesita enviar tráfico a un destino para el que no dispone de una ruta más específica.

    En una red doméstica, la puerta de enlace suele ser el router. Sin embargo, un router puede tener varias interfaces y participar en muchas rutas distintas.

    Para que la comunicación funcione, las interfaces, las rutas y los equipos deben estar correctamente configurados.

    6. ¿Qué ocurre cuando enviamos un paquete?

    Supongamos que el ordenador A (192.168.1.10/24) quiere comunicarse con el ordenador B (192.168.2.20/24).

    El proceso simplificado es el siguiente:

    1. El ordenador A examina la dirección IP de destino.
    2. Utiliza su dirección IP y su prefijo para determinar que el destino está en otra subred.
    3. Consulta su tabla de rutas para encontrar una ruta apropiada.
    4. Si la ruta seleccionada utiliza la puerta de enlace 192.168.1.1, el ordenador envía la trama al router.
    5. El router examina la dirección IP de destino y consulta su propia tabla de rutas.
    6. Si dispone de una ruta válida, reenvía el paquete hacia la red de destino.
    7. El ordenador B recibe el paquete si la comunicación está permitida y la configuración es correcta.

    El paquete IP mantiene normalmente sus direcciones IP de origen y destino durante el encaminamiento. En cada enlace, la trama de nivel 2 se construye con las direcciones correspondientes al enlace local.

    En una red Ethernet, el ordenador A necesita conocer la dirección MAC del siguiente salto, que en este ejemplo es la interfaz LAN del router. Para resolver direcciones IPv4 a direcciones MAC se utiliza ARP.

    7. ¿Qué sucede si el destino está en la misma red?

    Si el ordenador A quiere comunicarse con 192.168.1.20/24, el destino pertenece a la misma subred.

    En ese caso, el ordenador A intenta enviar la trama directamente al equipo de destino. No necesita utilizar la puerta de enlace para encaminar el tráfico entre redes.

    Si todavía no conoce la dirección MAC del destino, puede utilizar ARP para averiguarla.

    Este esquema es una simplificación: la selección de ruta puede incluir rutas específicas, rutas estáticas y otras configuraciones.

    8. ¿Qué es una tabla de rutas?

    La tabla de rutas contiene información que el sistema utiliza para decidir por dónde enviar los paquetes IP.

    En Linux podemos consultarla con:

    ip route

    Ejemplo de salida:

    default via 192.168.1.1 dev enp0s3
192.168.1.0/24 dev enp0s3 proto kernel scope link src 192.168.1.10

    La primera línea indica una ruta predeterminada:

    • default: se utiliza cuando no existe una ruta más específica que resulte aplicable.
    • via 192.168.1.1: indica el siguiente salto.
    • dev enp0s3: indica la interfaz de salida.

    La segunda línea representa la red directamente conectada:

    • 192.168.1.0/24: es el prefijo de destino.
    • dev enp0s3: es la interfaz asociada a esa red.
    • src 192.168.1.10: indica una dirección de origen preferida para esa ruta.

    Los nombres de interfaz y las direcciones variarán según el equipo.

    9. ¿Qué pasa si no hay una ruta adecuada?

    Si el equipo no encuentra una ruta aplicable al destino, no podrá enviar el paquete por una ruta válida.

    Si falta la ruta predeterminada, todavía podría comunicarse con destinos que tengan rutas más específicas, como los de su red local.

    Además, configurar una puerta de enlace no garantiza por sí solo que la comunicación funcione. El router debe tener una ruta hacia el destino y deben permitirse los paquetes a lo largo del recorrido.

    10. Conceptos clave

    • Red local: conjunto de equipos que comparten una subred IP y una conectividad local.
    • Router: dispositivo que encamina paquetes IP entre redes.
    • Puerta de enlace predeterminada: siguiente salto utilizado normalmente para destinos sin una ruta más específica.
    • Tabla de rutas: información que permite decidir cómo enviar los paquetes.
    • Ruta por defecto: ruta utilizada cuando no hay una ruta más específica aplicable.
    • ARP: protocolo que permite resolver una dirección IPv4 a una dirección MAC en una red local Ethernet.
