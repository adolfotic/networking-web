    Práctica de laboratorio: descubrir la configuración de red en Ubuntu

    1. Objetivos

    Al finalizar esta práctica, podrás:

    • Identificar las interfaces de red de un equipo.
    • Consultar su dirección IPv4 y su prefijo de red.
    • Reconocer la dirección de red a partir de una configuración sencilla.
    • Consultar la tabla de rutas y localizar la ruta por defecto.
    • Comprobar la conectividad con otros equipos.
    • Diferenciar un problema de conectividad local de uno que afecta a la comunicación con otras redes.

    2. Antes de empezar

    Realiza la práctica en un equipo Ubuntu o en una máquina virtual con una interfaz de red activa.

    Abre un terminal. No necesitas permisos de administrador para ejecutar los comandos de consulta de esta práctica.

    Importante: las direcciones IP de tu equipo pueden ser diferentes de las que aparecen en los ejemplos. Utiliza los valores reales que obtengas.

    3. Identificar las interfaces de red

    Ejecuta:

    ip addr

    Este comando muestra las interfaces de red y sus direcciones.

    Busca una interfaz que tenga una dirección IPv4, identificada por la palabra inet.

    Por ejemplo:

    inet 192.168.1.25/24

    Esta línea indica que la interfaz tiene la dirección IP 192.168.1.25 y utiliza el prefijo /24.

    En Ubuntu pueden aparecer nombres de interfaz como enp0s3, ens33 o eth0. El nombre depende del equipo y de su configuración.

    También puede aparecer lo, la interfaz de loopback utilizada para la comunicación interna del propio equipo.

    4. Interpretar la dirección y el prefijo

    Supongamos que obtenemos esta configuración:

    inet 192.168.1.25/24

    El prefijo /24 indica que 24 de los 32 bits de la dirección IPv4 pertenecen a la parte de red.

    En este caso, la máscara equivalente es:

    255.255.255.0

    Para una subred convencional /24, podemos identificar:

    • Dirección de red: 192.168.1.0
    • Dirección del equipo: 192.168.1.25
    • Dirección de broadcast: 192.168.1.255

    Estos valores son un ejemplo. Debes calcular los correspondientes a la configuración real de tu equipo.

    Si tu prefijo no es /24, no apliques directamente la regla de los tres primeros octetos. Calcula la red teniendo en cuenta el prefijo real.

    5. Consultar las rutas

    Ejecuta:

    ip route

    Este comando muestra la tabla de rutas del sistema.

    Una salida posible es:

    default via 192.168.1.1 dev enp0s3
192.168.1.0/24 dev enp0s3 proto kernel scope link src 192.168.1.25

    La primera línea indica una ruta por defecto: cuando el sistema necesita enviar tráfico a un destino para el que no tiene una ruta más específica, utiliza la puerta de enlace 192.168.1.1.

    La segunda línea indica una red directamente conectada a la interfaz.

    El nombre de la interfaz, la dirección de origen y las rutas pueden ser distintos en tu equipo.

    Actividad 3

    Responde consultando el resultado de ip route:

    1. ¿Qué interfaz se utiliza para llegar a la red local?
    2. ¿Aparece una ruta por defecto?
    3. Si aparece, ¿cuál es la dirección de la puerta de enlace?
    4. ¿Qué significa la palabra default?

    Si no aparece una ruta por defecto, anótalo y explica que no se puede identificar una puerta de enlace por defecto a partir de esa salida.

    6. Comprobar la conectividad

    El comando ping envía mensajes ICMP Echo Request y espera respuestas Echo Reply.

    Prueba primero la comunicación con tu propio equipo mediante loopback:

    ping -c 4 127.0.0.1

    Después, si has identificado la dirección de un equipo vecino o de tu puerta de enlace, puedes probar:

    ping -c 4 DIRECCION_IP

    Sustituye DIRECCION_IP por la dirección real del destino.

    Por ejemplo:

    ping -c 4 192.168.1.1

    Este ejemplo solo funcionará si esa es la dirección correcta de tu puerta de enlace y el destino responde a ICMP.

    Importante: que un ping no reciba respuesta no demuestra por sí solo que el equipo esté apagado o que la red esté averiada. Puede haber reglas de firewall o dispositivos que bloqueen ICMP.

    7. Preguntas de reflexión

    1. ¿Qué diferencia hay entre una dirección IP y una máscara?
    2. ¿Qué información proporciona el prefijo /24?
    3. ¿Para qué sirve la ruta por defecto?
    4. ¿Por qué dos equipos de redes distintas pueden necesitar un router?
    5. ¿Por qué un ping fallido no demuestra necesariamente que el destino esté desconectado?
    6. ¿Qué diferencia hay entre la interfaz lo y una interfaz Ethernet?

    8. Entrega

    Entrega un documento breve que contenga:

    • La salida relevante de ip addr.
    • La salida de ip route.
    • La tabla de configuración completada.
    • Los resultados de las pruebas de conectividad.
    • Las respuestas a las seis preguntas de reflexión.

    No incluyas contraseñas, claves privadas ni otra información sensible.
