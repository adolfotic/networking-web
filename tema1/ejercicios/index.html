    Ejercicios guiados: direcciones IP y máscaras

    En esta página practicaremos cómo interpretar direcciones IPv4, identificar la red a la que pertenece un equipo y reconocer las direcciones que se utilizan para identificar la red y enviar mensajes a todos los equipos de esa red.

    Por ahora trabajaremos principalmente con la máscara /24. Los cálculos binarios se estudiarán más adelante.

    1. ¿Están los equipos en la misma red?

    Consideremos una red local con la máscara 255.255.255.0, equivalente al prefijo /24.

    En este caso, los tres primeros números de la dirección IP identifican la red y el último identifica al equipo dentro de ella.

    flowchart TB
    A["Red: 192.168.1.0/24"]
    A --> B["Ordenador A<br/>192.168.1.10"]
    A --> C["Ordenador B<br/>192.168.1.20"]
    A --> D["Impresora<br/>192.168.1.30"]
    A --> E["Router<br/>192.168.1.1"]

    Todos estos dispositivos pertenecen a la misma subred.

    Ejemplo resuelto

    ¿Pertenecen a la misma red estas direcciones?

    • Equipo A: 192.168.1.10/24
    • Equipo B: 192.168.1.50/24

    Solución: sí. Ambos tienen los tres primeros octetos iguales: 192.168.1.

    Por tanto, pertenecen a la red 192.168.1.0/24.

    Segundo ejemplo

    • Equipo A: 192.168.1.10/24
    • Equipo B: 192.168.2.10/24

    Solución: no. El tercer octeto es diferente.

    El equipo A pertenece a 192.168.1.0/24 y el equipo B a 192.168.2.0/24.

    Para comunicarse entre estas redes normalmente será necesario un dispositivo de nivel 3, como un router, y una configuración de red adecuada.

    2. Dirección de red, equipos y broadcast

    En una subred IPv4 convencional, hay direcciones que cumplen funciones diferentes.

    Para la red 192.168.1.0/24:

    Elemento Dirección Función
    Dirección de red 192.168.1.0 Identifica la subred
    Primer host convencional 192.168.1.1 Puede asignarse a un equipo
    Último host convencional 192.168.1.254 Puede asignarse a un equipo
    Broadcast 192.168.1.255 Envío a todos los equipos de la subred

    Con esta máscara, la subred dispone de 256 direcciones en total. En el caso convencional, se reservan la dirección de red y la de broadcast, por lo que quedan 254 direcciones asignables a hosts.

    flowchart LR
    A["192.168.1.0<br/>Red"] --> B["192.168.1.1<br/>Primer host"]
    B --> C["...<br/>Hosts intermedios"]
    C --> D["192.168.1.254<br/>Último host"]
    D --> E["192.168.1.255<br/>Broadcast"]

    Importante: esta regla corresponde a una subred IPv4 convencional como /24. Existen casos especiales y prefijos para los que el tratamiento de las direcciones es diferente.

    3. Ejercicios propuestos

    Intenta resolverlos antes de consultar las soluciones.

    Ejercicio 1. Identificar la red

    Un ordenador tiene la dirección 192.168.10.25/24.

    1. ¿Cuál es su dirección de red?
    2. ¿Cuál es la dirección de broadcast?
    3. ¿Cuál es el rango convencional de direcciones asignables a hosts?

    Ejercicio 2. Comparar dos equipos

    Dos ordenadores tienen estas configuraciones:

    • Ordenador A: 192.168.5.12/24

    • Ordenador B: 192.168.5.200/24

    • ¿Pertenecen a la misma subred?

    • ¿Cuál es la dirección de red?
    • ¿Necesitan un router para comunicarse dentro de esa misma subred, suponiendo que no hay aislamiento ni otras restricciones?

    Ejercicio 3. Detectar una red diferente

    Tenemos estos dos equipos:

    • Ordenador A: 192.168.5.12/24

    • Ordenador B: 192.168.6.12/24

    • ¿Pertenecen a la misma subred?

    • ¿Cuál es la red de cada equipo?
    • ¿Qué dispositivo permitiría encaminar tráfico entre ambas redes?

    Ejercicio 4. Interpretar una configuración

    Un equipo tiene la siguiente configuración:

    • Dirección IP: 10.20.30.40
    • Máscara: 255.255.0.0
    • Prefijo: /16

    Responde:

    1. ¿Cuál es la dirección de red?
    2. ¿Qué parte de la dirección identifica la red?
    3. ¿Pertenecería a la misma subred un equipo con IP 10.20.99.15/16?

    Ejercicio 5. Detectar un error

    Un alumno configura dos equipos así:

    • Equipo A: 192.168.1.10/24
    • Equipo B: 192.168.1.255/24

    ¿Es correcta la dirección del equipo B para utilizarla como dirección de host convencional? Justifica la respuesta.

    4. Soluciones

    Solución del ejercicio 1 - Red: `192.168.10.0` - Broadcast: `192.168.10.255` - Hosts convencionales: desde `192.168.10.1` hasta `192.168.10.254`.
    Solución del ejercicio 2 Sí, ambos pertenecen a `192.168.5.0/24`. Al compartir subred, pueden comunicarse directamente a través de la red local, siempre que la configuración y los dispositivos lo permitan. No necesitan un router para encaminar tráfico entre ellos.
    Solución del ejercicio 3 No pertenecen a la misma subred. - Equipo A: `192.168.5.0/24` - Equipo B: `192.168.6.0/24` Un router, o un dispositivo de capa 3 correctamente configurado, puede encaminar tráfico entre ambas redes.
    Solución del ejercicio 4 - Red: `10.20.0.0/16` - La parte de red son los dos primeros octetos: `10.20`. - Sí. `10.20.99.15/16` pertenece a la misma subred.
    Solución del ejercicio 5 No. En una subred convencional `192.168.1.0/24`, la dirección `192.168.1.255` es la dirección de broadcast, no una dirección que deba asignarse a un host.

    5. Ideas fundamentales

    • La IP identifica una interfaz de red.
    • La máscara o el prefijo permiten determinar qué parte corresponde a la red y qué parte al host.
    • Dos equipos con la misma subred pueden comunicarse directamente dentro de la red local, si no existen restricciones.
    • Para comunicar redes IP diferentes normalmente se necesita encaminamiento mediante un router o dispositivo de capa 3.
    • En una subred IPv4 convencional, la dirección de red y la de broadcast no se asignan a hosts.
